1. Validate all fields.
2. Validate email.
3. Validate resume file.
4. Upload/process the resume securely.
5. Send an email to the configured Inclined Careers email address.
6. Attach the candidate's resume to the email.
7. Include all submitted candidate information in a clean HTML email.
8. Include the application timestamp.
9. Include the selected job/role.
10. Return a success response to the frontend.
