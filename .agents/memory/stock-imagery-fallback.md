---
name: Stock imagery fallback
description: Durable guidance for adding stock photography when the workspace image-search capability is unavailable.
---

Use a small, cohesive set of downloaded public stock images and reference them from the artifact's public assets rather than relying on runtime hotlinks.

**Why:** The workspace image-search capability may be unavailable in the current execution mode, while downloaded assets keep the preview and deployed site predictable.

**How to apply:** Prefer 3–4 editorially consistent images, reuse them in responsive image frames, and keep meaningful alt text on every content image.
